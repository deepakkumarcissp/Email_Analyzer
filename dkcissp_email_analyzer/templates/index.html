Analyze an email

Best results: the original message (Gmail → ⋮ → Show original, or an .eml file) so SPF/DKIM/DMARC can be read. A plain forwarded snippet also works — header authentication is then inferred from live domain checks. The suspicious link is never opened; reputation is only checked passively, and only if you've configured an API key. Nothing you paste here leaves your machine except optional, explicitly-configured lookups.
